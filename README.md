FangstPlot er ein applikasjon som kombinerar geografisk data frå Kartverket med fangst-data plotta inn av brukaren.

Brukaren markerar sitt lokale fiskeområde og får opp eit varmekart som visar sansynet for å få hummar i teina på dei ulike stadane.

Fangsplot er under utvikling, som denne ufullstendige README-fila tydeleggjer.
